
# Enterprise Deep Learning Sequence Model Deployment Suite

## Project Overview
This project implements an enterprise-style deep learning sequence classification system using Python, TensorFlow and Keras.

## Dataset
IMDB Movie Reviews Dataset.

The dataset contains positive and negative movie reviews for binary sentiment classification.

## Deep Learning Architectures
1. Long Short-Term Memory (LSTM)
2. Gated Recurrent Unit (GRU)
3. Bidirectional LSTM

## Implementation
- Dataset loading and exploration
- Text sequence preprocessing
- Vocabulary management and padding
- Deep learning model construction
- Model training and validation
- Performance evaluation
- Accuracy and loss visualization
- Confusion matrix analysis
- ROC curve comparison
- Best model selection
- Model saving and reloading
- Sentiment prediction on new reviews

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Outputs
- Trained LSTM, GRU and Bidirectional LSTM models
- Model performance comparison
- Accuracy and loss graphs
- Confusion matrices
- ROC curves
- Sentiment prediction results
- Model metadata and deployment documentation

## Conclusion
Successfully implemented and evaluated multiple deep learning sequence architectures for sentiment classification using the IMDB movie review dataset.
